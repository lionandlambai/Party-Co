# Party Co website — GitHub upload

This package contains the complete website source and gallery media.

Important hidden files are included in the ZIP:

- `.gitignore`
- `.openai/hosting.json`
- `.oxfmtrc.json`
- `.oxlintrc.json`

## Recommended upload

1. Extract the ZIP on your computer.
2. Create an empty GitHub repository.
3. Upload the extracted contents, keeping the folder structure unchanged.
4. Confirm that `.gitignore` and the `.openai` folder appear in the repository.

The project uses Node.js 22 or newer. Install dependencies with `npm install`, run it locally with `npm run dev`, and create a production build with `npm run build`.
